# Yora.tj — HTML5-баннеры

150 анимированных креативов: 25 размеров × 3 сообщения × 2 языка. Собраны из макета Figma
[`vazifa_tj`](https://www.figma.com/design/IBXDFTKO9J4ouoT2gvk5go/vazifa_tj?node-id=2803-25623)
по скиллу [`banner-builder`](https://github.com/komilovsg/banner-builder).

Открыть все сразу — корневой `index.html` собирает их в галерею:

```bash
python3 -m http.server 8899
open http://127.0.0.1:8899/
```

Каждый креатив при этом остаётся отдельной самодостаточной страницей со своим
адресом (`out/<сообщение>-<язык>/<ШxВ>/`) — галерея только показывает их рядом через
`<iframe>`, площадке отдаётся папка или ZIP.

На Vercel деплоится статикой как есть: `vercel.json` отключает установку
зависимостей и сборку, `.vercelignore` выкидывает исходники и `refs/` (14 MB
эталонных рендеров Figma), в деплой едут только `index.html`, `out/` и `dist/`.

## Что откуда

В Figma каждая сцена нарисована двумя кадрами: в первом слои стоят за пределами
холста, во втором — на своих местах. Разница между кадрами и есть анимация.

Шесть размеров взяты из макета покадрово. Остальные восемнадцать макет на момент
сборки не отдал (квота Figma на `/files/:key/nodes` держалась часами), поэтому их
раскладки выведены генератором — см. «Раскладки без макета».

| Сообщение | RU | TJ | Клик ведёт на |
|---|---|---|---|
| Работодателю | Найдите своего сотрудника! | Корманди худро пайдо кунед! | `yora.tj/ru` |
| Соискателю | У нас вакансия! | Мо ҷойи корӣ дорем! | `yora.tj/ru/vacancies?currency_id=2&page=1` |
| Имиджевый | Yora.tj — вакансии по всему Таджикистану! | Yora.tj — ҷойҳои корӣ дар тамоми Тоҷикистон! | `yora.tj` |

## Вес

Два разных потолка: Google Ads — 150 KB в архиве, Яндекс для HTML5 — 512 KB.

19 из 24 размеров укладываются в 150 KB (самый тяжёлый — 1024×768, 148 KB).
Пять крупных CPM-форматов — 1080×1350, 1440×1440, 1920×1080, 1080×1920,
1440×1800 — весят 208–318 KB: мимо Google, но с запасом под Яндекс. В списки
размеров Google они всё равно не входят.

Фон режется @2x до 600 px по большей стороне и @1x выше — на 1920×1080 удвоение
даёт JPEG на 3840 px, деталей которого никто не увидит, а бюджет съедает.

## Раскладки без макета

`scripts/derive-layouts.mjs` собирает размер, которого нет в комплекте кадров.
Набор один и тот же — логотип, заголовок, подпись, кнопка, контакты — меняется
расстановка. Три семейства по пропорциям:

- **stacked** — вертикали и квадраты: композиция макета, всё по центру;
- **leaderboard** (`w/h > 2.2`) — логотип слева, сообщение в центре, кнопка справа;
- **strip** (`h < 70`) — то же, но без подписи.

Кегль берётся от макетного (заголовок 16.59 / подпись 9.92 / кнопка 11.06 /
контакты 8.79 при 160×600), растёт под холст и **уменьшается шагами, пока блок
реально не поместится**. Проверяется и ширина самой длинной строки: перенос по
словам не спасает, если одно слово шире колонки — на 320×100 заголовок из-за
этого налезал на логотип.

На 320×50 и 320×100 с длинным заголовком кнопка не помещается вместе с ним.
Макет на этих полосках её и не рисует, поэтому генератор пробует вариант с
кнопкой, а не влезло — собирает без неё. Кликабелен весь баннер.

## Решения

**Без GSAP.** Каждый слой едет по прямой один раз — это CSS `@keyframes` умеет
сам, а библиотека стоила бы ~25 KB в архиве. Стаггер живёт внутри одного общего
5-секундного цикла процентами, потому что `animation-delay` срабатывает один раз,
а не на каждой итерации.

**Текст набирается локально.** Сначала слои экспортировались контурами из Figma,
но её рендер-эндпоинт лимитирует запросы часовой квотой, а таджикских кадров для
новых размеров в макете нет вообще. `LoosVar` нашёлся в `yora-web-client` —
вариативный, оси `wght` 0–1000 и `wdth` 0–1000, все таджикские глифы на месте.
`scripts/lib/typeset.mjs` набирает текст и отдаёт контуры; сверено с экспортом
Figma — те же переносы, те же габариты в пределах пикселя.

Две ловушки шрифта. Обе оси по умолчанию **0**: запросив только вес, получаешь
Compressed, на 28% уже, и все переносы разъезжаются. И веса не отображаются на
начертания напрямую — Figma называет точный инстанс в `fontPostScriptName`:
заголовки `Extended Black`, подписи и контакты `Wide Regular`, кнопки
`Wide Medium`. Инстанс берётся по имени, оси не подбираются.

**Фон — один растр на сцену.** Все шесть сцен используют одну картинку
1920×1080, но положена она тремя разными способами; `absoluteBoundingBox` для
двух из них врёт:

- сцены 1–2 — узел 1182×665, режим `FILL`;
- сцены 3–4 — узел 1782×1002, **повёрнут на 14.1°**. Его bounding box 1972×1406 —
  это габарит повёрнутого прямоугольника, а не сам прямоугольник. Если брать
  габарит за размер, фон растягивается и диагональные блики уезжают;
- сцены 5–6 — узел 1763×992, режим `STRETCH` со сдвигом `imageTransform` на 40 px.

`scripts/build-bg.mjs` считает это по `size` + `relativeTransform` и вырезает
готовое окно 160×600 @2x — 26–36 KB JPEG.

**Рамка — оверлеем.** `border` на `#banner` сдвигает все абсолютно
спозиционированные слои на 1 px внутрь от координат Figma. Рамка нарисована
через `::after`, поэтому Google видит край, а вёрстка не едет.

**Контакты переразложены.** В макете это одна строка `@weyora | +992 553 06 2222`;
по заданию нужны две строки и покрупнее. Просить у Figma рендер каждого TEXT-узла
отдельно не вышло — эндпоинт рендера жёстко лимитирует запросы, а сам макет править
нельзя. Поэтому `scripts/split-contacts.mjs` перевыпускает уже скачанный SVG дважды
с обрезанным `viewBox`: те же векторы, просто окно. Обе строки берут одну и ту же
вертикальную полосу, иначе у них разъехался бы масштаб глифов — у `@weyora` есть
выносной элемент, у номера нет.

Блок центрирован и увеличен в 1.35×. У сцены «У нас вакансия» контактов в макете
не было — взяты из соседней.

**Позиция блока считается по фону, а не на глаз.** Кнопка с контактами скользит
вверх, каждое положение оценивается средней яркостью фона под текстом, берётся
самое тёмное; вниз блок не уходит — так у `jobseeker` кнопка уезжала к нижнему
краю и в середине оставалась дыра. Где даже наверху яркость выше 140 из 255,
под контакты кладётся мягкое радиальное затемнение: позиция и композиция
сохраняются, читаемость появляется.

## Тайминги

Цикл 5 с, 3 прохода = 15 с (IAB LEAN). Въезд слоёв сверху вниз, внахлёст,
0.15–1.8 с; дальше кадр с CTA стоит ~3.2 с. Ease `power3.out`, у кнопки
`back.out(1.6)`. У `jobseeker-tj` фон дополнительно панорамируется на 30 px —
это есть в макете. Есть `prefers-reduced-motion`: анимация отключается,
показывается финальный кадр.

## Проверка

```bash
node scripts/verify.mjs      # рендер @2x + пиксельный диф с макетом Figma
node scripts/filmstrip.mjs employer-ru
bash ~/Developer/baner-animation-html/scripts/check.sh out/ 150
```

`verify.mjs` перебирает сдвиги ±3 px и ищет лучшее совмещение с макетом. Проверка
писалась до правок по контактам, поэтому теперь она честно показывает расхождение
в нижней трети баннера — там мы намеренно ушли от макета (две строки вместо одной,
масштаб, подъём). Верх — фон, логотип, заголовок, подпись — по-прежнему должен
совмещаться в `0,0`.

## Сборка с нуля

```bash
npm install
echo 'figd_...' > .figma-token     # Personal access token, scope file_content:read
node scripts/fetch-figma.mjs       # кадры PNG + nodes.json (секция 160x600)
node scripts/fetch-sizes.mjs       # nodes-<ШxВ>.json для остальных секций
node scripts/build-spec.mjs        # геометрия и вектор смещения по парам кадров
node scripts/render-layers.mjs     # контуры слоёв локально, без Figma
node scripts/split-contacts.mjs    # строка контактов -> телеграм + телефон
node scripts/derive-tj.mjs         # таджикские версии макетных размеров
node scripts/derive-layouts.mjs    # раскладки размеров, которых нет в макете
node scripts/build-bg.mjs          # фоны под каждый размер
node scripts/build-banners.mjs     # out/<сообщение>-<язык>/<ШxВ>/
node scripts/build-index.mjs       # галерея
bash ~/Developer/baner-animation-html/scripts/backup.sh out/ 5
```

## Допущения

- Посадочная страница задаётся по сообщению, не по языку: RU- и TJ-версия одного
  креатива ведут на один адрес. Меняется в `CLICK` в `scripts/build-banners.mjs`.
  `https://yora.tj/` редиректит на `/ru`, поэтому имиджевый и «работодатель`
  фактически приземляются на одну страницу.
- Размер только 160×600 — других в макете нет. Под 300×250 / 728×90 нужна
  отдельная раскладка, а не масштабирование этой.
- Таджикские креативы помечены `tj` — по принятому в компании обозначению, включая
  атрибут `lang="tj"`. По BCP-47 код таджикского языка `tg`, поэтому HTML-валидатор
  на `lang="tj"` ругнётся. Это осознанно, не опечатка.
